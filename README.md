# ML-projects

This repository contains my machine learning projects, built while learning and practicing ML.

## 📂 Projects
1. [Linear Regression on Student Performance](linear_regression_1.ipynb)  
   - Predicting math scores using demographic and test-related features.  
   - Techniques: One-Hot Encoding, Linear Regression, Model Evaluation (MSE, R²).
2. [Urban Environmental AQI Prediction](polished_predict_aqi.ipynb)  
   - Predicting Air Quality Index (AQI) using urban environmental factors  
   - Dataset: `urban_environmental_data.csv`  
   - Techniques: Data Cleaning, EDA, Feature Engineering, Linear Regression, Random Forest, Gradient Boosting  
   - Model Export: `final_model.pkl` + `requirements.txt` for easy deployment  


## ⚙️ Tech Stack

- Pandas, NumPy
- Jupyter/Google Colab
